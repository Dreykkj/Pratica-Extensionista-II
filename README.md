# Pratica-Extensionista-II
Nosso projeto e relatório sobre o nosso aplicativo chamado Praxio

RELATÓRIO DE DESENVOLVIMENTO
Grupo: Andrey, Eduardo, Logan e Ray

1. Introdução

Este documento detalha as ações efetuadas durante a construção do aplicativo Praxio. Este projeto foi criado com o objetivo de ajudar estudantes a gerenciar seus afazeres, encontros e obrigações de estudo.

A proposta central é fornecer um instrumento descomplicado e útil, onde o estudante possa registrar suas lembretes, estabelecer prazos e horários, e supervisionar suas ocupações através de um calendário.

2. Desenvolvimento do projeto

A construção do Praxio usou HTML, CSS e JavaScript. A primeira seção é a página de entrada, onde aparecem as recordações registradas, seus prazos, horários e tipos. Há também um card que exibe a quantidade de afazeres em espera, distinguindo testes e trabalhos. A segunda seção é o calendário, que mostra um calendário completo. Nela, o usuário pode se mover entre os meses, escolher um dia em particular e ver os compromissos registrados para esse período.

3. Funcionalidades implementadas

Ao longo da construção, estas funções foram adicionadas:
- Registro de lembretes: possibilita adicionar tarefas indicando nome, detalhe, tipo, data e hora
- Modificação de lembretes: oferece a chance de alterar os dados de uma tarefa já anotada
- Apagar lembretes: possibilita retirar tarefas que não são mais requeridas
- Finalização de tarefas: permite marcar um lembrete como terminado ou desfazê-lo
- Calendário completo: possibilita avançar e voltar entre os meses e escolher dias específicos
- Reconhecimento de compromissos: exibe uma marcação nos dias que contêm lembretes anotados
- Exibição da agenda: mostra os eventos conforme o dia escolhido 
- Sumário de afazeres: revela a contagem de tarefas à espera, testes e trabalhos na tela de entrada
- Guarda de dados: preserva os avisos guardados no navegador mesmo após o fechamento da página

4. Ferramentas usadas
HTML, CSS, JAVASCRIPT E LOCALSTORAGE

Mais para frente, o programa poderá ter novas aprimorações, como notificações, registro de matérias e união com um repositório para guardar os dados de um modo melhor.
