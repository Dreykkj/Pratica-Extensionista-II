# Pratica-Extensionista-II
Nosso projeto e relatório sobre o nosso aplicativo chamado Praxio

O Práxio é um app de lembretes para estudantes, é possível cadastrar prova, trabalho e tarefas pessoais, e ver o que está pendente na tela inicial e conferir tudo por dia em uma agenda com calendário.

O que usamos
HTML pra montar a estrutura das telas, o menu e o formulário
CSS para o visual
JavaScript para toda a lógica

O projeto tem 3 arquivos: index.html, style.css e script.js.

Cada tarefa guarda título, descrição, categoria (prova, trabalho ou pessoal), data, horário, ícone e se já foi concluída.
O botão “+” abre um formulário pra criar ou editar a tarefa.
A tela inicial mostra a lista ordenada por data e horário. A agenda mostra um calendário mensal e os eventos do dia escolhido.
Dá pra concluir, editar e excluir tarefas direto pela lista.
